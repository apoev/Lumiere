# Lumiere

Лёгкий macOS-плеер. Интерфейс свой, декодирование — libvlc из установленного VLC, поэтому редкие контейнеры и кодеки читаются так же, как в VLC, а само приложение не тащит копию кодеков.

- Плейлист: файлы, папка, перетаскивание. В конце ролика включается следующий.
- На панели: пауза, перемотка на 10 секунд, скорость, громкость.
- Картинка в картинке — отдельное окно поверх остальных пространств, со своей перемоткой и скоростью. Системный пузырь PiP такие кнопки не принимает, поэтому окно своё.

Нужен установленный [VLC](https://www.videolan.org/) (проверено на 3.0). Сборка как у Mimir: Xcode.app не обязателен, приложение собирается `swiftc` в `.app`.

```bash
cd /Users/apoev/Documents/AppCursor/Lumiere
./Scripts/build.sh run
```

Готовое приложение: `build/Lumiere.app` и копия в «Программах».

Если Gatekeeper не пускает на другом Mac, рядом со сборкой лежит `разрешить-запуск.command`.
